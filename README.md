# SwiftUI 90 Days

My 90-day journey learning SwiftUI and building AI-integrated iOS apps
after a career break, upgrading from UIKit/Storyboard experience.

## Progress

- **Day 1:** Learned NavigationStack, @Observable, async/await, and actor
  basics. Built a small "Team Directory" demo app to see all four concepts
  working together.

- **Day 2:** Learned the View protocol, VStack/HStack/ZStack layout, and
  modifier order. Built a 3-tab demo app (Form, List, Detail screens) to
  practice layout basics from scratch.
